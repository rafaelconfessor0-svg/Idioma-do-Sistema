# 🌐 Idioma do Sistema - Java

## 📖 Sobre o projeto

Este projeto foi desenvolvido em Java utilizando Swing para identificar e exibir o idioma configurado no sistema operacional do usuário.

O objetivo é demonstrar a utilização da classe `Locale` da linguagem Java para obter informações do sistema de forma simples e prática.

## 🚀 Tecnologias utilizadas

- Java
- Java Swing
- Maven
- NetBeans

## 🎯 Objetivo

Praticar:
- Programação Orientada a Objetos (POO)
- Manipulação de interfaces gráficas (Swing)
- Uso da classe `Locale`
- Integração entre Java e informações do sistema operacional

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto no NetBeans.
3. Execute a aplicação.
